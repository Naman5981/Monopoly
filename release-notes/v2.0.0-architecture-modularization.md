## 🌟 Executive Summary

Prior to v2.0.0, the entire 3D visual diorama existed in a single monolithic source file: `src/three/scene.js`, spanning **4,504 lines and 212 KB**. This monolith coupled camera math, procedural avatar generation, vehicle AI, diorama bases, lighting, 2D canvas texture baking, dice physics, and input raycasting into a single tangled state.

In **v2.0.0**, the 3D layer was completely modularized into **19 decoupled, single-responsibility submodules** organized under [world-tycoon/src/three](file:///c:/Users/karti/OneDrive/Desktop/Anti%20Gravity/Monopoly/Monopoly/world-tycoon/src/three). The file [src/three/scene.js](file:///c:/Users/karti/OneDrive/Desktop/Anti%20Gravity/Monopoly/Monopoly/world-tycoon/src/three/scene.js) was converted into a **184-line Facade**, preserving 100% backward compatibility for all external callers with zero breaking changes.

## 📐 Directory & Submodule Architecture

```
world-tycoon/src/three/
├── scene.js                 # Facade coordinating init & re-exporting public APIs (<190 lines)
│
├── core/                    # Engine runtime, camera, lighting, input, render loop
│   ├── context.js           # Shared Three.js state & mesh registries (singleton store)
│   ├── camera.js            # Orthographic isometric camera, damping & mouse-wheel zoom
│   ├── lighting.js          # Directional sun, shadows, 12 cast-iron street lamps & themes
│   ├── input.js             # Pointer dragging, 45° angle snapping, hover tooltips & click raycasting
│   └── loop.js              # 60FPS animation & rendering loop
│
├── board/                   # Diorama base, grid coordinates, tiles, and spring physics
│   ├── coords.js            # Geometry constants, grid step metrics & tile world coordinates
│   ├── diorama.js           # Mahogany stepped pedestal, lawn, fountain & pine trees
│   ├── tiles.js             # 2D canvas textures, 3D tile meshes & upgrade synchronization
│   ├── tilePress.js         # Physical spring depression animation on step / click
│   └── highlights.js        # Selection rings, active player beacon & flight runway halos
│
├── assets/                  # Procedural 3D models & physics generators
│   ├── avatars.js           # Characters (skins, suits, ties, blinking eyes, custom hats)
│   ├── buildings.js         # Houses (L1-L3), skyscrapers (L4/L5), flags & chimney smoke
│   ├── landmarks.js         # 4 corner landmarks (Start Arch, Castaway Tower, Festival Stage, Jetliner)
│   └── dice.js              # Chamfered 3D dice meshes & tumbling physics animation
│
├── pawns/                   # Character pawn traversal, speech bubbles, and portraits
│   ├── tokens.js            # Token spawning, multi-pawn spacing & 3D HUD portraits
│   ├── movement.js          # Parabolic hopping trajectories & World Tour flight cruising
│   └── speech.js            # Screen-projected speech & reaction emote bubbles
│
├── stages/                  # Dedicated modal viewports and mini-scenes
│   ├── lobbyStage.js        # Floating grassy lobby hero customizer podium
│   └── cityPreview.js       # Modal 3D property inspector rotating diorama
│
└── environment/             # Ambient background life & weather
    ├── cars.js              # 5 procedural vehicles with roadway track physics & traffic AI
    └── clouds.js            # Low-poly drifting clouds & festival hot-air balloon
```

## 🐛 Bug Fixes Included in v2.0.0

- **Undeclared `arcHeight` Bug:** Fixed a runtime `ReferenceError: arcHeight is not defined` in `scene.js:3604` during pawn hopping. Properly declared and calculated as `const arcHeight = Math.sin(rawT * Math.PI) * 0.95;` in [pawns/movement.js](file:///c:/Users/karti/OneDrive/Desktop/Anti%20Gravity/Monopoly/Monopoly/world-tycoon/src/three/pawns/movement.js#L55).
- **PowerShell Path Spacing:** Quoted script execution and compilation paths in `server.ps1`, `build_exe.ps1`, `build_zip.ps1`, and `package_distribution.ps1` to prevent failures when workspaces contain spaces (e.g. `Anti Gravity`).
- **Launcher Non-Interactive Crash:** Resolved `InvalidOperationException: Cannot read keys when either application does not have a console or when console input has been redirected` in [Launcher.cs](file:///c:/Users/karti/OneDrive/Desktop/Anti%20Gravity/Monopoly/Monopoly/Launcher.cs).
